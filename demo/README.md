# Demo

The whole Aperta thesis in one run against the bundled lab:

```sh
npm run demo        # or: node demo/demo.mjs
```

It drives the shipped CLI (`bin/aperta.mjs`) exactly as a user would, against the deliberately
vulnerable lab in `../lab`:

1. **reconstruct** the stripped bundle into the full surface, including the hidden `/api/admin/*`
   endpoints a low-privilege user never sees;
2. **diff** low-priv `alice` against `admin` to isolate the surface `alice` is gated from;
3. **prove** a cross-user BOLA (`alice` reads `bob`'s order), confirmed by the app's own sibling
   endpoint `/api/me/orders` with own-id=200 and nonexistent=404 controls holding in the same run.

The lab bundle is gitignored; the first run builds it automatically (`npm install && npm run build`
inside `../lab`). The demo logs in to mint the two sessions for you; in real use you supply those
from your own proxy history (Aperta never logs in).

A captured, de-colored transcript lives in [`money-shot.txt`](money-shot.txt).

## Recording a GIF

One command, one dependency (the `agg` binary, which the script fetches if you lack it):

```sh
./demo/record-gif.sh          # -> demo/money-shot.gif
```

It renders [`money-shot.cast`](money-shot.cast) (a checked-in asciinema recording generated by
`node demo/make-cast.mjs`, no asciinema needed) into the GIF. Prefer a real live capture? With
asciinema installed: `asciinema rec demo/money-shot.cast -c "node demo/demo.mjs --pace"`, then run
the script to convert it.
